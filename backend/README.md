# Notice Decoder — Backend API

Backend REST API for **Notice Decoder**, built with Node.js, Express, and Supabase.

---

│   │

## 🛠️ Prerequisites & Installation

1. Ensure **Node.js** (v18+ recommended) is installed:
   ```bash
   node -v
   ```

2. Open a terminal in the `backend` folder and install dependencies:
   ```bash
   cd backend
   npm install
   ```

---

## ⚙️ Environment Configuration

1. Copy `.env.example` to `.env`:
   ```bash
   cp .env.example .env
   ```
2. Open `.env` and fill in your Supabase credentials:
   ```env
   PORT=5000
   SUPABASE_URL=https://your-project-id.supabase.co
   SUPABASE_KEY=your-supabase-anon-public-key
   GROK_API_KEY=your-grok-api-key-here
   ```
   > ⚠️ **Security Note**: Never commit `.env` or real API keys to GitHub.

---

## 🗄️ Supabase Database Setup

1. Go to your [Supabase Dashboard](https://supabase.com/dashboard).
2. Open the **SQL Editor** tab from the left sidebar.
3. Paste and run the contents of [`schema.sql`](./schema.sql):

```sql
-- 1. Create 'notices' table
CREATE TABLE IF NOT EXISTS notices (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  original_text TEXT NOT NULL,
  summary TEXT,
  date TEXT,
  time TEXT,
  venue TEXT,
  target_audience TEXT,
  required_action TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 2. Create 'events' table
CREATE TABLE IF NOT EXISTS events (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  title TEXT NOT NULL,
  date TEXT NOT NULL,
  time TEXT,
  venue TEXT,
  description TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Enable RLS and add basic policies
ALTER TABLE notices ENABLE ROW LEVEL SECURITY;
ALTER TABLE events ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Allow public read notices" ON notices FOR SELECT USING (true);
CREATE POLICY "Allow public insert notices" ON notices FOR INSERT WITH CHECK (true);

CREATE POLICY "Allow public read events" ON events FOR SELECT USING (true);
CREATE POLICY "Allow public insert events" ON events FOR INSERT WITH CHECK (true);
```

4. Retrieve your **Project URL** and **anon public API Key** from **Project Settings -> API** and add them to `.env`.

## 🚀 Running the Backend

### Development Mode (with automatic restart using Nodemon):
```bash
npm run dev
```

### Production Mode:
```bash
npm start
```

The server will start on `http://localhost:5000`.

## 🧪 Postman Testing Guide

You can test all endpoints directly with Postman without needing the frontend.

### Test 1: Health Check
* **Method:** `GET`
* **URL:** `http://localhost:5000/`
* **Expected Response:** `200 OK`
```json
{
  "message": "Notice Decoder Backend is running!"
}
```

---

### Test 2: Submit a Notice
* **Method:** `POST`
* **URL:** `http://localhost:5000/api/notices`
* **Headers:** `Content-Type: application/json`
* **Body (raw JSON):**
```json
{
  "text": "The college will conduct a workshop on 25 October 2026 at 10 AM in Seminar Hall. All second year students must attend."
}
```
* **Expected Response:** `201 Created`
```json
{
  "message": "Notice processed and saved successfully.",
  "notice": {
    "id": 1,
    "original_text": "The college will conduct a workshop on 25 October 2026 at 10 AM in Seminar Hall. All second year students must attend.",
    "summary": "The college will conduct a workshop on 25 October 2026 at 10 AM in Seminar Hall",
    "date": "25 October 2026",
    "time": "10 AM",
    "venue": "Seminar Hall",
    "target_audience": "second year students",
    "required_action": "must attend",
    "created_at": "2026-10-16T18:15:00.000Z"
  }
}
```

---
